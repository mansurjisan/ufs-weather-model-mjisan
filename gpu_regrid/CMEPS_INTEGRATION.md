# CMEPS GPU Regridding Integration Guide

This document describes how to integrate the GPU-accelerated regridding module
with CMEPS (Community Mediator for Earth Prediction Systems) for UFS coastal
applications.

## Overview

ESMF regridding is fundamentally a sparse matrix-vector multiply (SpMV):

```
dst_field = W * src_field
```

Where `W` is a sparse weight matrix generated by ESMF. Our GPU implementation:
1. Extracts weights from ESMF during `FieldRegridStore()`
2. Converts COO format to CSR format for GPU efficiency
3. Replaces `FieldRegrid()` calls with GPU SpMV operations

**Performance**: 3.4x speedup on NVIDIA H100 with GPU-resident data.

## Step 1: Copy GPU Module to CMEPS

```bash
cp gpu_regrid/cmeps_mediator/gpu_regrid_mod.F90 \
   CMEPS-interface/CMEPS/mediator/
```

## Step 2: Modify CMakeLists.txt

Add GPU build option to `CMEPS-interface/CMEPS/CMakeLists.txt`:

```cmake
# Near the top, add option
option(GPU_REGRID "Enable GPU-accelerated regridding" OFF)

# In the source file list, add conditionally
if(GPU_REGRID)
  list(APPEND _mediator_files
    mediator/gpu_regrid_mod.F90
  )

  # Set OpenACC flags for NVIDIA
  if(CMAKE_Fortran_COMPILER_ID MATCHES "NVHPC")
    set(CMAKE_Fortran_FLAGS "${CMAKE_Fortran_FLAGS} -acc -gpu=cc80,cc90 -Minfo=accel")
  endif()
endif()
```

## Step 3: Modify med_map_mod.F90

### 3.1 Add Module Use Statement

At the top of `med_map_mod.F90`, add:

```fortran
#ifdef GPU_REGRID
  use gpu_regrid_mod, only : gpu_regrid_init, gpu_regrid_store_weights, &
                              gpu_regrid_apply, gpu_regrid_available, &
                              gpu_regrid_finalize
#endif
```

### 3.2 Initialize GPU Module

In `med_map_init()` or early in the mediator initialization:

```fortran
#ifdef GPU_REGRID
  integer :: gpu_rc
  call gpu_regrid_init(gpu_rc)
  if (gpu_rc /= 0) then
    call ESMF_LogWrite('GPU regrid init failed, using CPU fallback', ESMF_LOGMSG_WARNING)
  end if
#endif
```

### 3.3 Extract and Store Weights

In `med_map_routehandles_init()` where `ESMF_FieldRegridStore()` is called,
extract the weights using the `factorList` and `factorIndexList` parameters:

```fortran
! Original ESMF call (simplified)
call ESMF_FieldRegridStore(field_src, field_dst, routehandle=RH, &
     regridmethod=maptype, &
     unmappedaction=ESMF_UNMAPPEDACTION_IGNORE, &
     factorList=factorList, &           ! ADD: weight values
     factorIndexList=factorIndexList, & ! ADD: (2,nnz) row,col indices
     rc=rc)

#ifdef GPU_REGRID
! Store weights for GPU use
if (allocated(factorList) .and. size(factorList) > 0) then
  call gpu_regrid_store_weights( &
       compid_src, compid_dst, mapindex, &
       factorList, factorIndexList, &
       src_size, dst_size, gpu_rc)
  if (gpu_rc /= 0) then
    call ESMF_LogWrite('GPU weight storage failed', ESMF_LOGMSG_WARNING)
  end if
end if
#endif
```

**Important**: The `factorIndexList` array has shape `(2, nnz)` where:
- `factorIndexList(1,:)` = destination (row) indices (1-based)
- `factorIndexList(2,:)` = source (column) indices (1-based)

### 3.4 Replace FieldRegrid Calls

In `med_map_field()` or wherever `ESMF_FieldRegrid()` is called:

```fortran
subroutine med_map_field(field_src, field_dst, RH, compid_src, compid_dst, mapindex, rc)
  ! ... existing declarations ...

  real(R8), pointer :: src_ptr(:), dst_ptr(:)
  integer :: gpu_rc

#ifdef GPU_REGRID
  ! Check if GPU regridding is available for this mapping
  if (gpu_regrid_available(compid_src, compid_dst, mapindex)) then

    ! Get field data pointers
    call ESMF_FieldGet(field_src, farrayPtr=src_ptr, rc=rc)
    if (ChkErr(rc,__LINE__,u_FILE_u)) return

    call ESMF_FieldGet(field_dst, farrayPtr=dst_ptr, rc=rc)
    if (ChkErr(rc,__LINE__,u_FILE_u)) return

    ! Apply GPU regridding
    call gpu_regrid_apply(compid_src, compid_dst, mapindex, &
         src_ptr, dst_ptr, gpu_rc)

    if (gpu_rc == 0) then
      ! GPU regrid succeeded
      rc = ESMF_SUCCESS
      return
    else
      ! Fall back to ESMF
      call ESMF_LogWrite('GPU regrid failed, falling back to ESMF', &
           ESMF_LOGMSG_WARNING)
    end if
  end if
#endif

  ! Original ESMF regridding (fallback or non-GPU build)
  call ESMF_FieldRegrid(field_src, field_dst, RH, &
       zeroregion=ESMF_REGION_TOTAL, &
       termorderflag=ESMF_TERMORDER_SRCSEQ, &
       rc=rc)

end subroutine med_map_field
```

### 3.5 Cleanup

In `med_map_finalize()` or mediator finalization:

```fortran
#ifdef GPU_REGRID
  call gpu_regrid_finalize(gpu_rc)
#endif
```

## Step 5: Runtime Considerations

### GPU Memory

Each cached regrid mapping uses approximately:
- `8 * nnz` bytes for weights (double precision)
- `4 * nnz` bytes for column indices
- `4 * (nrows+1)` bytes for row pointers

For a typical DATM→SCHISM mapping with 2M non-zeros:
- ~24 MB GPU memory per mapping

### Data Locality

For best performance (3.4x speedup), keep field data on GPU:

```fortran
! Use OpenACC data regions to keep data on GPU
!$acc data copyin(src_fields) copy(dst_fields)

do timestep = 1, nsteps
  ! ... model physics (on GPU) ...

  ! Regridding (data already on GPU)
  call gpu_regrid_apply(...)

  ! ... more physics ...
end do

!$acc end data
```

### Component Identifiers

The GPU module uses integer identifiers to match mappings. Use CMEPS component
indices consistently:

| Component | Typical ID |
|-----------|------------|
| DATM      | 1          |
| SCHISM    | 2          |
| WW3       | 3          |

## Verification

To verify GPU regridding produces correct results:

1. Run with `GPU_REGRID=OFF` and save output
2. Run with `GPU_REGRID=ON` and compare
3. Expected difference: < 1e-14 (machine precision)

## Troubleshooting

### No GPU Available

If no GPU is detected, the module automatically falls back to CPU:
```
GPU_REGRID: No GPU available, will use CPU fallback
```

### Weight Extraction Fails

If `factorList` is not allocated after `FieldRegridStore()`, check:
- ESMF version (requires 8.1+)
- Memory allocation for large grids

### Performance Not as Expected

- Ensure data stays on GPU between calls (use `present_or_copyin`)
- Check for implicit data transfers in surrounding code
- Use `NVCOMPILER_ACC_TIME=1` to profile GPU operations
